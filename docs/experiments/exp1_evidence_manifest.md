## 5. Epistemic Demarcation: Raw Evidence vs. Derived Metrics vs. Interpretation

To maintain strict scientific demarcation, all reported quantities are categorized into their exact epistemic status:

### 5.1 Category A: Direct Raw Empirical Measurements
These values were directly captured by instrumented monotonic timers, integer counters, and tensor solvers:
- **Total Integration Wall-Clock Time ($T_{\text{total}}$):** Measured in-process around the `odeint` solve call via `time.perf_counter_ns()` across 15 recorded repetitions.
- **Integer Evaluation Count ($\text{NFE}$):** Exactly counted via wrapper forward call counter `node.nfe`.
- **Isolated Evaluation Latency ($T_f$):** Directly bench-tested via 1,000 passes on 50 sampled trajectory coordinates using `time.perf_counter_ns()`:
  - FitzHugh-Nagumo: $T_f = 24.6000\ \mu\text{s}$ ($\text{IQR} = 1.0000\ \mu\text{s}$)
  - Lotka-Volterra: $T_f = 24.6000\ \mu\text{s}$ ($\text{IQR} = 0.9000\ \mu\text{s}$)
- **Raw Repetition Arrays:** All 15 individual measurement timings preserved in `raw_runtimes_ms`.

### 5.2 Category B: Derived Analytical & Statistical Metrics
These values are mathematical transformations computed from Category A raw evidence:
- **Non-Parametric Summary Statistics:**
  - $\text{runtime\_ms\_median} = \text{Median}(T_1, \dots, T_{15})$
  - $\text{runtime\_ms\_iqr} = Q_3(T) - Q_1(T)$
- **Estimated Isolated Network Runtime:**
  $$\widehat{T}_{\text{net}} = \frac{\text{NFE}_{\text{median}} \times T_{f, \text{median}}}{1000.0} \quad (\text{ms})$$
  *(Epistemic boundary: This is a synthetic estimate based on multiplying isolated benchmark latency by NFE; it is NOT an in-situ timer measurement).*
- **Estimated Solver Housekeeping Overhead:**
  $$\widehat{T}_{\text{solver}} = T_{\text{total, median}} - \widehat{T}_{\text{net}} \quad (\text{ms})$$
  *(Epistemic boundary: This represents the residual difference between measured total time and isolated network latency; it is NOT directly instrumented CPU execution cycles inside the solver algorithm).*
- **Estimated Solver Overhead Ratio:**
  $$\widehat{\Omega}_{\text{solver}} = \frac{\widehat{T}_{\text{solver}}}{T_{\text{total, median}}}$$
- **Disaggregated OLS Linear Regressions:**
  - Series 1A: $\beta_1 = 0.127435\ \text{ms/NFE}$ ($127.44 \pm 3.49\ \mu\text{s/NFE}$), $\beta_0 = +2.0414\ \text{ms}$, $R^2 = 0.994051$
  - Series 1B: $\beta_1 = 0.138736\ \text{ms/NFE}$ ($138.74 \pm 2.33\ \mu\text{s/NFE}$), $\beta_0 = -0.4761\ \text{ms}$, $R^2 = 0.997757$
  - Series 1C: $\beta_1 = 0.052629\ \text{ms/NFE}$ ($52.63 \pm 0.57\ \mu\text{s/NFE}$), $\beta_0 = +4.4575\ \text{ms}$, $R^2 = 0.999534$
- **Numerical Accuracy Metrics:**
  - $\text{MSE}$, $\text{Rel-}L_2$, and $L_\infty$ computed via `CubicSpline` interpolation against high-precision Radau reference trajectories (`rtol=1e-10, atol=1e-12`).

### 5.3 Category C: Scientific Interpretations & Inferences
These conclusions represent empirical deductions drawn from Category A and B:
- **Within-Series Linearity:** NFE linearly predicts wall-clock runtime within any single unconfounded solver-system ladder ($R^2 \ge 0.994$).
- **Solver-Dependent Disparity:** In this experimental setup, adaptive `dopri5` integration incurred a **$2.42\times$ higher marginal wall-clock cost per NFE** than fixed-step `rk4` ($127.44\ \mu\text{s}$ vs. $52.63\ \mu\text{s}$).
- **System-Dependent Disparity:** Under identical architecture and tolerances, FitzHugh-Nagumo exhibited an **$8.87\%$ higher marginal cost per NFE** than Lotka-Volterra ($138.74\ \mu\text{s}$ vs. $127.44\ \mu\text{s}$).
- **Surrogate Error vs. Solver Error:** As step size $h \to 0$ in Series 1C, the numerical solution converged to $\text{MSE} = 1.9213$, confirming that residual discrepancy at $T=15.0$ reflects surrogate generalization drift, not solver breakdown.
